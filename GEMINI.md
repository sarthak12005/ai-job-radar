# Project Rules & Guidelines

## Git Operations Rule (Strictly Enforced)
- **NO AGENT COMMITS OR PUSHES**: The AI assistant / agent is **strictly forbidden** from executing `git commit`, `git push`, or any command that commits changes or pushes code to any remote repository.
- **User Ownership**: All staging, committing, branching, and pushing to GitHub/remote repositories will be performed manually and exclusively by the user (`Sarthak Joshi`).
- **Allowed Git Commands**: The agent is only permitted to run read-only git status queries (`git status`, `git diff`, `git log`) to verify local file integrity.
